OpenClaw API

简洁强大的API接口，快速集成AI能力到您的应用

RESTful API设计

OpenClaw API采用标准的RESTful设计，支持HTTP/HTTPS协议，提供完善的SDK和文档，让您可以在几分钟内完成集成。

  • 兼容OpenAI API格式
  • 支持流式响应
  • 多模型切换
  • 自定义参数配置
  • 详细的错误处理
Python
import requests # 调用OpenClaw API response = requests.post( "http://localhost:8000/v1/chat/completions", headers={"Authorization": "Bearer YOUR_API_KEY"}, json={ "model": "qwen3.5-4b", "messages": [ {"role": "user", "content": "你好"} ], "stream": True } ) for chunk in response.iter_lines(): print(chunk.decode("utf-8"))
